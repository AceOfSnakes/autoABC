# Contributing

Keep the supported platform and immutable release payloads in mind. File an issue for reproducible disc-specific problems, including firmware family, source type (physical HDMV, physical BD-J, ISO or BDMV), relevant `ISO_BDMV` setting, player symptoms and **redacted** status/log excerpts.

Do not attach copyrighted movie files, commercial disc images, NAND backups, proprietary player executables, device secrets or keys. Submit original test scripts and analytical notes only if you have the right to share them. Distinguish observations on real hardware, offline reproduction, reasoned inferences and untested hypotheses.

A code change that alters a runtime hook, firmware signature, installer transaction or uninstall restore path needs a fresh static/integrity audit **and** a live regression test. Cosmetic renaming of internal binary protocols is not safe.

Contributions must be original or accompanied by applicable permissions; see [License status](LICENSE-STATUS.md).
