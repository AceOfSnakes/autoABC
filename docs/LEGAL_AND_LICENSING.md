# Project origin and distribution

autoABC is an independently developed community modification based on examining the supported OPPO UDP-203 RU-JB firmware environment. The repository contains integration scripts, documentation and verification tools. The release ZIPs also contain compiled helpers and firmware-specific hook/signature data; they do **not** include a complete OPPO firmware image.

The project does not claim rights over OPPO firmware, trademarks or third-party materials and is not affiliated with OPPO Digital. Technical references are listed in [Sources](SOURCES.md).
