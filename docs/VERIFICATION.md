## Offline acceptance

The final published ZIPs were prepared from the R8 candidate without modifications to the runtime, firmware hooks or installer/uninstaller logic. In the recorded final offline verification:

- **96/96** host-simulated full CHECKONLY → INSTALL → ALREADY_INSTALLED → UNINSTALL/restoration cycles passed, including recognized jb_overlay, combined boot chains and MKV-only, all option combinations, KEY8 and newline edge cases.
- **13/13** focused safety/negative cases passed, including unsupported owners and signatures, changed config and EJECT outcomes.
- **4/4** default `EARLYBOOT=1` and **2/2** edited `EARLYBOOT=0` integration cycles passed.
- Archive CRCs, inner manifests, published outer SHA-256s and script syntax checks passed.
- **39/39** unchanged native/binary hook and BusyBox payloads matched the earlier known working R6 lineage.

These are **offline** results using modeled firmware/process behavior, not a substitute for on-device first-disc, tray or Blu-ray tests. Maintainer and external tester feedback exists for particular firmware/boot layouts but does not certify every player.

## Live verification

Run CHECKONLY on the actual player before installing; only `COMPATIBLE` qualifies the specific verified environment. After install, power-cycle and check `INSTALLED` plus runtime status using the [Telnet cheatsheet](../README.md#telnet--ssh-quick-reference). During BD-J playback consider both the region register and PSR20 gate.
