# Security and responsible reporting

This modification uses runtime memory hooks and an early-boot wrapper. Installation on unverified firmware may render a player unstable or unbootable. Report unexpected bootstrap, signature-check, backup/restore, or integrity behavior privately to the repository maintainer before publishing device-specific exploit details or logs.

Do not post NAND dumps, personal configuration, credentials, MAC addresses, secret keys or full proprietary firmware binaries in issues. Redact local paths and device identifiers from diagnostic logs. There is no supported universal recovery procedure; retain your own verified backup and recovery route before installing.

No guarantee is made for other models or unrecognized patched firmware.
